# Algorithm/DSA Collection (idi-open)

This repository contains a collection of algorithm implementations and exercise scripts (mostly in Python and C) used for learning and practicing algorithms. It appears to be a set of assignments / examples rather than a polished competitive programming library.

## ✅ What’s included

**Core categories (examples):**
- **Graph algorithms**: Dijkstra, Bellman-Ford style examples, minimum spanning trees, max flow, bipartite matching
- **Shortest paths**: Dijkstra, DAG shortest path, Floyd-Warshall, Schulze method
- **Sorting / selection**: Counting sort, insertion sort, merge sort, k-largest
- **Dynamic programming**: Longest decreasing subsequence, grid paths, sheet cutting
- **NP-hard / combinatorial problems**: TSP verification, unimodal sequence search, Huffman encoding
- **Misc**: DAWG DNA example, nim game, linear programming example

## ⚠️ What this repo is NOT

- It is not a polished competitive programming library.
- Many scripts are written as exercise / classroom code and include debugging prints, early `exit()` calls, and custom test harnesses.
- There are no standardized input/output conventions (stdin/stdout) or reusable library modules.

## ✅ Improvements applied in this repo (clean-up)

- Removed compiled binaries and build artifacts (e.g., `dijkstra`, `merge`, `huffman`, `priority-queue`, etc.) so only source files remain.
- Added a `.gitignore` to prevent accidental check-in of compiled executables and Python caches.
