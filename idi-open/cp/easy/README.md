# Easy practice problems

This folder contains small, standalone scripts for very easy contest problems.
They are intended as warm-ups and as examples of standard input/output formatting.

## Included problems

- **sort_numbers.py** - sort an array of integers
- **binary_search.py** - binary search on a sorted array
- **connected_components.py** - count connected components in an undirected graph

## How to run

```sh
python -m cp.easy.sort_numbers < input.txt
```

Each script reads from stdin and writes to stdout.
